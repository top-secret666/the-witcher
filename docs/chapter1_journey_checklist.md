# Chapter 1 — чеклист канонического пути

Канон (фазы директора):

`SHOP → BOSS_MAP → LOOP_SEQUENCE → BOSS_ENCOUNTER → SWORD_CUTSCENE → BATTLE_RESULT → SHOP`

Выдача карты — состояние лавки `BATTLE_CARD_REVEAL` (как кошелёк), не фаза `Chapter1Phase`.

## Ручная приёмка

1. Запустить игру, дойти до лавки главы 1.
2. В сумке **нет** иконки карты боя до экипировки.
3. Купить → экипировка → надеть предмет(ы).
4. Нажать **«Назад»** из экипировки → катсцена карты (как мешочек денег) → иконка в сумке.
5. Клик по карте в сумке → **карта боссов** (курсор, выбор).
6. Клик по боссу → **loop_wake** (пробуждение, веки).
7. Веки закрываются → тёмный экран → открываются → **лес + злодей** → диалог.
8. Клик по диалогу → **проблески мечей** на чёрном (спрайт-листы).
9. Экран **победы/поражения** → клик → снова лавка.

## Не ломать при правках

- Визуал лавки / карты / век / мечей не менять «вслепую» в этом этапе.
- Не возвращать фазы `CARD_REVEAL` / `BOSS_SPLASH` в директор без новой задачи.
