# Chapter 1 — чеклист канонического пути

Канон (фазы директора):

`SHOP → BOSS_MAP → BOSS_QUEST_BRIEFING → LOOP_SEQUENCE → BOSS_ENCOUNTER → BOSS_FINALE → [BOSS_GLITCH_REVEAL] → WOLF_ENDING → SHOP`

- Выдача карты — состояние лавки `BATTLE_CARD_REVEAL` (как кошелёк), не фаза `Chapter1Phase`.
- Проблески мечей (rush sheet) — VFX на шаге `BOSS_FINALE.CLASH`, не отдельная фаза.
- Ветка `BOSS_GLITCH_REVEAL` только при истинном осколке; иначе сразу `WOLF_ENDING`.

См. также `Chapter1CanonicalJourney` в домене.

## Ручная приёмка

1. Запустить игру, дойти до лавки главы 1.
2. В сумке **нет** иконки карты боя до экипировки.
3. Купить → экипировка → надеть предмет(ы).
4. Нажать **«Назад»** из экипировки → катсцена карты (как мешочек денег) → иконка в сумке.
5. Клик по карте в сумке → **карта боссов**.
6. Клик по боссу → **брифинг** (ложный контракт) → выбор → уход.
7. **loop_wake** (пробуждение, веки) → тёмный экран → открываются → **лес + злодей** → диалог/выбор.
8. После энкоунтера → **финал** (выбор) → **проблески мечей** на чёрном → исход.
9. Экран **WOLF_ENDING** (петля или осколок, намёк про статы) → клик → снова лавка.

## Legacy / не канон

| Фаза / вход | Назначение |
|---|---|
| `BATTLE_RESULT` | Старый экран победы/поражения; канон использует `WOLF_ENDING` |
| `VN_BATTLE` | Debug: `Ctrl+B` в лавке; не связан с cinematic-путём |
| `LOOP_HOLD` | Заготовка illusion_wrong; из канона не стартует |
| `HACK` / `ENDING` | Meta-путь терминала / побега |

## Persist между запусками

- Meta главы (`Chapter1Save`): петля, suspicion/trust, флаги Волка, терминал и т.п.
- Лавка каждый раз — новая сессия магазина; карта боя снова через экип → reveal.
- После плохого исхода Волка: `LoopRules.onWolfBadLoop` (новый виток).
- После осколка: `LoopRules.onWolfTrueShard` (сохранить без сброса петли).

## Не ломать при правках

- Не возвращать фазы `CARD_REVEAL` / `BOSS_SPLASH` / `SWORD_CUTSCENE` в enum без новой задачи.
- Визуал лавки / карты / век / мечей не менять «вслепую» вне полировки VFX.
