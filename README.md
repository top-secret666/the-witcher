# The Witcher — Chapter 1 Prototype

Pixel-art Java prototype: shop loop, wolf boss, VN dialogues.

## Run (Windows)

1. Clone or download this repository.
2. Double-click **`The Witcher.exe`** in the project root.

No Java install required — the bundled `runtime/` folder is used automatically.  
Keep `The Witcher.exe`, `app/`, and `runtime/` in the same directory.

## Source code

Java sources and legacy Gradle/LibGDX layout are under **`dev/`**.
